# Shashank Khare — AI Product & Transformation Leader

Personal portfolio website, built with static HTML, CSS and JavaScript for GitHub Pages.

## Publish

Repository: https://github.com/kshashank-stack/shashank-khare-portfolio

In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

Expected URL: https://kshashank-stack.github.io/shashank-khare-portfolio/

## Structure
- index.html — site content
- styles.css — responsive dark/light design
- script.js — mobile navigation and current year
- assets/favicon.svg — site icon
